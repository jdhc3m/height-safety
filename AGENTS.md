# Agent Instructions

AI agents working in this repository must:

1. Read `PROJECT_CONTEXT.md`
2. Read the decision and assumption registers
3. Preserve evidence classifications and confidence levels
4. Cite sources for domain claims
5. Record uncertainty instead of guessing

During Stage 2A, agents must not:

- Write production code
- Design the final database
- Design the final API
- Define the final MVP
- Invent compliance requirements
- Treat public templates or competitor features as authoritative requirements

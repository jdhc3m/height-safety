Guardrails carried into every screen
Recorded outcome, submitted by inspector, reviewed by, draft report, further assessment required. No certification, automatic compliance, standards compliance, engineer approval or replacement of professional judgement. Supported jurisdiction is recorded context only and never infers legal rules, intervals, authority or compliance. Tenant isolation, durable offline evidence, idempotent sync, photograph association, conflict visibility, report revisions and auditability are preserved.

Exception path A — changes requested
Review → request changes (reviewer, time, reason, affected records recorded) → job moves to changes_requested → inspector edits a new working revision on Android → resubmit → server assigns a new inspection revision → review again. Submitted history stays visible; inspector evidence is never silently overwritten.
Exception path B — approval blocked
Approve action → gate rejects: hard blockers (cannot be waived), warnings needing a recorded reason, open change requests, pending/failed uploads. Reviewer resolves each or requests changes. Approval only succeeds when every hard blocker is clear, then freezes the exact snapshot.

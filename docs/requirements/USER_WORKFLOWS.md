# User Workflows

1. Office creates client, site and installed-anchor register, manually or by
   import.
2. Office creates job, selects site and assigns one inspector.
3. Inspector downloads assigned job pack and sees existing anchors/history.
4. Inspector opens each anchor, records observations, notes, photographs,
   defects, recommendations and one provisional outcome.
5. Inspector records inaccessible/unable-to-locate cases and can add a newly
   discovered anchor. Local saves survive restart and connectivity loss.
6. Inspector submits; mutations and photographs synchronise with visible state.
7. Reviewer sees submitted jobs, missing fields, failed uploads and conflicts;
   requests changes or records review actions without silent evidence overwrite.
8. Connected reviewer generates a neutral prototype draft PDF.
9. Report revision stores immutable file, source inspection snapshot, template
   version, users, timestamp and audit history.

# Founder Context

## Purpose

This document records project context supplied by the founder. It is not
domain validation or legal advice.

## Current strategy

Build a narrow, credible anchor-inspection prototype; create a fictional
demonstration job; show it to inspection companies; collect workflow
corrections; secure one design partner; adapt only where repeated practical
feedback supports it; then run a controlled pilot in parallel with the
partner's existing authoritative process.

## Product posture

Prototype workflow awaiting professional validation. The application earns
access to industry knowledge; it is not presented as a completed professional
compliance platform.

## Initial operating assumptions

New South Wales and Queensland, small inspection companies, Android field use,
web office use, limited offline operation, draft reports, one primary inspector
per job and a design-partner pilot able to validate both states. All remain
subject to the discovery register.

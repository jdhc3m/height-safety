# Draft Report Requirements

The first template is neutral and visibly labelled **Prototype Draft Inspection
Report**. It may include, where data is available: inspecting company, client,
site, job reference, inspection date, inspector, reviewer, anchor register,
anchor identifier and location, recorded observations, photographs, recorded
outcome, defects, recommendations, report-generation date, revision number and
the prototype disclaimer.

Use this disclaimer:

> This report was generated using an early-stage inspection workflow prototype. Inspection outcomes, technical decisions and report approval remain the responsibility of the inspecting organisation and its authorised personnel.

An issued revision must not silently change after later edits. Each revision
preserves or references the exact source inspection revision, template version,
creation timestamp, creating user, reviewing user when applicable, revision
number, generated file and relevant audit events. “Issued”, if used by a
partner, is an organisation-controlled term; the product generates a draft.
